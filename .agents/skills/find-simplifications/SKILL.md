# Find Simplifications (主动减熵与过度设计巡检)

在代码库中主动搜寻无生产消费者的冗余设计，为 Context 和代码库瘦身。

## 重点猎杀目标

1. **瞬时事件与持久事件的重复映射**：两个表示镜像同一个事实。
2. **无外部消费者的公开接口/配置旋钮**。
3. **投机通用性（Speculative Generality）**：仅为“未来可能用到”编写的多层抽象。
4. **仅为单次测试而存在的非承重代码**。

## 纪律要求

- 简化必须要有**扎实证据**（调用链缺失、单消费者证明）。
- 刻意保留的双后端或适配器（见相关架构 Note）不得盲目删除。
