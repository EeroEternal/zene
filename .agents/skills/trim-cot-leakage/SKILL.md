# Trim CoT Leakage (会话视角与思维链泄漏清洗)

用于检查代码变更、注释或文档草稿，确保其完全站在仓库 HEAD 视角，没有残留的单次会话临时脚手架。

## 猎杀目标

1. **死掉的会话引用**：`(decision 7)`、`阶段标签 (T4/W3)`、`设计台账`、`内部审计码`。
2. **时序与 PR 视角**：`这个 PR 加了`、`上一轮尝试`、`不再使用旧的`、`如前文所述`。
3. **审阅辩解**：`审阅者确认`、`这个 cast 是安全的只是为了通过检查`。

## 执行准则

- **当一段话带有事实时**：先把事实重述为 HEAD 独立成立的声明式状态，再剥离周围会话转录。
- **当一段话纯粹是会话叙述时**：整句删除。
