Zen Engine • 禅引擎

The Open, Minimalist
Coding-Agent Harness

A headless, composable agent harness speaking Agent Client Protocol (ACP). Built for IDEs, autonomous loops, and developer agents with prefix-cached context projection and sandboxed tool execution.

curl -fsSL https://zene.sh/install.sh | bash

Core Principles & Capabilities

🔌
Agent Client Protocol (ACP)
Native stdio JSON-RPC implementation connecting headless agents to external editors (Zed, Cursor, VS Code) and automation daemons.
⚡
Prefix-Cached Context Engine
Append-only event-driven context projection designed specifically for LLM prompt caching (Anthropic, OpenAI-compatible gateways) with intelligent auto-compaction.
🧘
Zen Boundaries & Zero UI
Core is strictly headless and composable. No heavy web consoles, bloated UI hydration, or unmediated network IO embedded in core.
🎛️
Turn Engine & Steer Buffers
Pi-aligned turn lifecycle supporting real-time steering and follow-up message queues without interrupting active agent loop boundaries.
🛡️
Sandboxed Tool Execution
Local subprocess isolation, permission gates (Default, AcceptEdits, BypassPermissions), approval brokers, and async MCP manager.
📦
Zero-Boilerplate Rust SDK
Instant single-line agent initialization via Agent::core(".") or Agent::minimal(".") with pre-configured lightweight toolsets.

Quickstart

Terminal • CLI & ACP Server bash 
# 1. Install pre-built binary
curl -fsSL https://zene.sh/install.sh | bash

# 2. Run ACP protocol server (communicates over stdio JSON-RPC)
zene acp

# 3. Inspect configuration and saved sessions
zene config
zene sessions

Embedding in Rust (`zene-core`)

Rust SDK • Minimalist Harness Embedding rust 
use zene_core::Agent;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // Single-line read-only probe agent (Read, Grep, Glob)
    let mut probe = Agent::minimal(".")
        .bypass_permissions()
        .build()
        .await?;

    let summary = probe.prompt("Analyze the codebase structure", Default::default()).await?;
    println!("{summary}");

    // Standard core agent harness with full local coding capabilities (Read, Write, Edit, Bash)
    let mut agent = Agent::core(".")
        .bypass_permissions()
        .build()
        .await?;

    agent.prompt("Run cargo clippy and fix any unused warnings", Default::default()).await?;
    Ok(())
}
