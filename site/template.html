ZEN ENGINE ARCHITECTURE / EDITION 2024

The Open, Minimalist Coding-Agent Harness

Zene is a headless, composable agent harness speaking Agent Client Protocol (ACP) for external editors (Zed, Cursor, VS Code) and automation daemons. Built with prefix-cached context projection, durable turn sessions, and sandboxed tool execution.

Core Principles & System Boundaries

Modular abstractions built strictly for headless runtime performance and durable execution.

PROTOCOL
Agent Client Protocol (ACP)
Native stdio JSON-RPC implementation connecting headless agents to external editors (Zed, Cursor, VS Code) and automation daemons.
CONTEXT
Prefix-Cached Context Engine
Append-only event-driven context projection designed specifically for LLM prompt caching with intelligent auto-compaction.
HARNESS
Zen Boundaries & Zero UI
Core is strictly headless and composable. Never introduce web consoles, bloated UI hydration, or unmediated network IO embedded in core.
LIFECYCLE
Turn Engine & Steer Buffers
Pi-aligned turn lifecycle supporting real-time steering and follow-up message queues without interrupting active agent loop boundaries.
SECURITY
Sandboxed Tool Execution
Local subprocess isolation, permission gates (Default, AcceptEdits, BypassPermissions), approval brokers, and async MCP manager.
EMBEDDING
Zero-Boilerplate Rust SDK
Instant single-line agent initialization via Agent::core(".") or Agent::minimal(".") with pre-configured lightweight toolsets.
