# zene-session

Session persistence for [Zene](https://github.com/ParaTensor/zene) agents: transcript storage, compaction history, checkpoints, and todos.

## Features

- `SessionRecord` with messages, compactions, todos
- Compaction checkpoints for `/rewind`
- JSON session files under `~/.zene/sessions`
- `AgentRecordWriter` for structured run logs
